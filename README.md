# 六库商业案例可视化

需求、流量、营销、变现、壁垒和案例六个维度的静态研究界面。

在线访问：[GitHub Pages](https://liangzai4322.github.io/bianxian-ku-visualization/)

## 页面

- [变现库](https://liangzai4322.github.io/bianxian-ku-visualization/)
- [流量库](https://liangzai4322.github.io/bianxian-ku-visualization/traffic-index.html)
- [营销库](https://liangzai4322.github.io/bianxian-ku-visualization/marketing-index.html)
- [需求库](https://liangzai4322.github.io/bianxian-ku-visualization/demand/)
- [壁垒库](https://liangzai4322.github.io/bianxian-ku-visualization/barrier/)
- [案例库](https://liangzai4322.github.io/bianxian-ku-visualization/case/)

同一案例使用稳定 `entity_id` 联动。页面启动时只加载当前库的轻量映射，展开关联或打开案例全景时才按需加载一个详情分片。

该仓库只保存生成后的静态站点。原始数据、备份、构建脚本和凭据不公开。
